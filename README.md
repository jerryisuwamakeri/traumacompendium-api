# TraumaCompendium — Backend

> Learn. Heal. Connect. Stay Safe.

Go backend for TraumaCompendium, a trauma education & recovery platform. This
repository currently implements the **Phase 1 core foundation**: authentication
& profiles, the Beginner learning level, journaling, and mood/trigger tracking.

Full documentation is being built up incrementally alongside the code — see
`docs/openapi.yaml` for the API contract as it grows.
